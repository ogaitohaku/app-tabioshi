# タビオシ

推しの旅を、そのまま予約。旅インフルエンサーの動画に出てきた宿・お店・回った順番を、自分の旅にできる Web アプリ(スマホのホーム画面に置けます)。

> いまはサンプルデータで動いています。人物・宿・お店・料金・口コミはすべて架空です。

## できること

| 画面 | 内容 |
| --- | --- |
| はじめての方へ `/welcome` | 合言葉、使い方の4ステップ、試作であること、予約・支払いは外部サイトで行うこと |
| ホーム `/` | はじめての案内、あなた向けの旅、エリア、推しの旅人、推しが泊まった宿、今日の1問 |
| 旅ショート `/shorts` | 1本ずつ縦にスワイプする旅動画。泊まった宿の「空室を見る」と「まるごとコピー」 |
| 旅 `/trips/[id]` | 動画に出てくる順の旅程と地図、1人あたりの目安、予習の豆知識とクイズ、共有 |
| 宿・お店 `/places/[id]` | 推しのひとこと、料金、口コミ、予約ボタン(外部サイトへ)、PR表示 |
| エリア `/areas/[id]` | その街の推しの旅と、宿・ごはん・お土産・スポット |
| 推し `/creators/[id]` | プロフィールと旅の一覧 |
| 旅マップ `/map` | 指で回して拡大できる地球儀。推しが行った場所のピン |
| マイ旅 `/me` | まるごとコピーした旅(いまはこの端末にだけ保存) |
| 旅タイプ診断 `/type` | 20問の旅タイプ診断(試作)、16タイプの結果、友だちとの相性 |
| 規約・ポリシー `/terms` `/privacy` `/tokushoho` | 利用規約・プライバシーポリシー・特定商取引法に基づく表示(いずれも専門家確認前の案。会社情報は `src/lib/company.ts`) |

## 動かし方

Node.js 22 以上が必要です。

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番用にビルド
npm run lint
```

## 中身(コンテンツ)の差し替え

- 人物・動画・宿・お店・クイズは `src/data/sample.ts` にあります。型は `src/data/types.ts`。
- 写真は `public/photos/` に置いて、`visual.photo` に `/photos/ファイル名.jpg` を書くと、イメージ画像の代わりに表示されます。
- 宿の予約先は `stay.booking` に書きます。
  - 楽天トラベルの施設番号: `{ rakutenHotelNo: "12345" }`
  - それ以外の予約サイト: `{ url: "https://..." }`
- 掲載料をもらっている宿・お店は `sponsored: true` にすると、画面に必ず「PR」と出ます。
- 本物のデータに切り替えたら、`src/data/sample.ts` の `IS_SAMPLE` を `false` にすると「サンプルです」の注記が消えます。

## 予約のしくみ

タビオシでは予約を受けず、楽天トラベルなどの予約サイトに送ります(アフィリエイト)。楽天アフィリエイトの紹介IDを環境変数 `NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` に入れると、予約ボタンが紹介リンクになります。`.env.example` を参照してください。

## 公開(デプロイ)

Vercel か Netlify にこのリポジトリをつなぐと、`main` に入るたびに自動で公開されます。環境変数 `NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` は公開先の設定画面で入れてください。

## 次にやること

- 旅タイプ診断を OGATYPE v2(OGA 共通の診断)に切り替える。採点の仕組みは OGATYPE チームのものを使い、ここでは作らない
- 実在のクリエイターと掲載データへの入れ替え、楽天アフィリエイトIDの設定
- ログインとデータベース。マイ旅を端末をまたいで保存する
- 規約類を OGA 共通のひな形に合わせて仕上げ、専門家の確認を受ける

予約と旅行代金の支払いは、これからも外部の予約サイトで行います(旅行業の登録がないため)。

## 見た目のルール

OGA 統一ルール(明るい業務サービス風)に合わせています。白地＋グレー＋朱1色、グラデーション・すりガラスなし、文字は12px以上、ボタンは44px以上。

## 地図データ

地球儀の陸地は [Natural Earth](https://www.naturalearthdata.com/)(パブリックドメイン)をもとにしています。
