# タビオシ

推しの旅を、そのまま予約。旅インフルエンサーの動画に出てきた宿・お店・回った順番を、自分の旅にできる Web アプリ(スマホのホーム画面に置けます)。

> いまはサンプルデータで動いています。人物・宿・お店・料金・口コミはすべて架空です。

## できること(最初の版)

| 画面 | 内容 |
| --- | --- |
| ホーム `/` | 旅の一覧、推しの旅人、推しが泊まった宿 |
| 旅ショート `/shorts` | 縦スクロールの旅動画。泊まった宿の「空室を見る」と「まるごとコピー」 |
| 旅 `/trips/[id]` | 動画に出てくる順の旅程、1人あたりの目安、予習の豆知識とクイズ |
| 宿・お店 `/places/[id]` | 推しのひとこと、料金、口コミ、予約ボタン(外部サイトへ)、PR表示 |
| 推し `/creators/[id]` | プロフィールと旅の一覧 |
| 旅マップ `/map` | 指で回して拡大できる地球儀。推しが行った場所のピン |
| マイ旅 `/me` | まるごとコピーした旅(いまはこの端末にだけ保存) |

## 動かし方

Node.js 22 以上が必要です。

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番用にビルド
npm run lint
```

## 中身(コンテンツ)の差し替え

- 人物・動画・宿・お店・クイズは `src/data/sample.ts` にあります。型は `src/data/types.ts`。
- 写真は `public/photos/` に置いて、`visual.photo` に `/photos/ファイル名.jpg` を書くと、イメージ画像の代わりに表示されます。
- 宿の予約先は `stay.booking` に書きます。
  - 楽天トラベルの施設番号: `{ rakutenHotelNo: "12345" }`
  - それ以外の予約サイト: `{ url: "https://..." }`
- 掲載料をもらっている宿・お店は `sponsored: true` にすると、画面に必ず「PR」と出ます。
- 本物のデータに切り替えたら、`src/data/sample.ts` の `IS_SAMPLE` を `false` にすると「サンプルです」の注記が消えます。

## 予約のしくみ

タビオシでは予約を受けず、楽天トラベルなどの予約サイトに送ります(アフィリエイト)。楽天アフィリエイトの紹介IDを環境変数 `NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` に入れると、予約ボタンが紹介リンクになります。`.env.example` を参照してください。

## 公開(デプロイ)

Vercel か Netlify にこのリポジトリをつなぐと、`main` に入るたびに自動で公開されます。環境変数 `NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` は公開先の設定画面で入れてください。
